# iNotes — Личные заметки в стиле Apple Notes с Яндекс Диском

**iNotes** — современное PWA веб-приложение для заметок в дизайне Apple Notes с поддержкой работы на **Android**, **iPhone** и **MacBook** и облачной синхронизацией через ваш личный **Яндекс Диск**.

## Возможности

- ☁️ **Двусторонняя синхронизация через Яндекс Диск** между всеми вашими устройствами.
- 📎 **Прикрепление файлов до 200 МБ** на файл (фотографии, видео, PDF, Word, Excel, ZIP, аудио).
- 📷 **Сканирование документов с камеры**: оптимизация контраста для четкого чтения текста на документах.
- 🎙️ **Голосовые заметки (Диктофон)**: запись аудио прямо внутри заметки с встроенным плеером.
- 🗑️ **Корзина («Недавно удалённые»)**: защита от случайного удаления, восстановление заметок или очистка корзины.
- 📋 **Вставка из буфера обмена (Ctrl+V / Cmd+V)** и перетаскивание файлов мышкой (Drag & Drop).
- 📁 **Структура папок на Яндекс Диске**:
  - `iNotes/Фотографии`
  - `iNotes/Видео`
  - `iNotes/PDF и документы`
  - `iNotes/Другие файлы`
  - `iNotes/notes.json`
- ☷ **Списки дел и чек-листы**.
- ⌑ **Закрепление важных заметок** вверху списка.
- 🔍 **Мгновенный поиск** по заголовкам и тексту заметок.
- 🌓 **Светлая и тёмная тема** в стиле iOS / macOS.
- 📱 **PWA-установка**: на Android (через Chrome) и на iPhone (через Safari «На экран Домой»).
