# iNotes — Android PWA

iNotes — устанавливаемое веб-приложение для Android в стиле Apple Notes. Включает заметки, поиск, папки, закрепление, чек-листы, тёмную тему, локальное хранение и заготовленную облачную синхронизацию через Firebase Authentication + Cloud Firestore.

## Важно перед использованием

- Без Firebase приложение работает локально в браузере на одном устройстве.
- Для синхронизации между устройствами нужен ваш Firebase-проект. В архиве нет чужого аккаунта или готового облачного сервера.
- Не публикуйте приватные ключи сервисных аккаунтов. В `firebase-config.js` используются публичные web-конфигурационные значения Firebase; безопасность обеспечивают Authentication и Firestore Rules.
- Прототип не является официальным приложением Apple и не связан с Apple.

## 1. Создайте Firebase-проект

1. Откройте https://console.firebase.google.com/ и создайте проект.
2. В настройках проекта добавьте Web App (значок `</>`).
3. Скопируйте `apiKey`, `authDomain`, `projectId` и `appId`.
4. Включите **Authentication → Sign-in method → Email/Password**.
5. Создайте **Firestore Database** (Production mode).
6. Откройте вкладку Rules и вставьте содержимое файла `firestore.rules`, затем нажмите Publish.
7. В `firebase-config.js` замените значения-заглушки на конфигурацию своего Web App.

Данные хранятся отдельно для каждого пользователя по пути `users/{uid}/notes/{noteId}`. Правила разрешают пользователю читать и менять только собственные заметки.

## 2. Разместите приложение в интернете (HTTPS)

Самый простой путь — Firebase Hosting:

1. Установите Node.js и Firebase CLI на компьютер: `npm install -g firebase-tools`.
2. Войдите: `firebase login`.
3. В папке проекта выполните `firebase init hosting`, выберите существующий Firebase-проект, укажите текущую папку как public directory и настройте SPA rewrite (можно ответить No для single-page app).
4. Выполните `firebase deploy`.
5. Откройте полученный HTTPS-адрес на Android.

Можно использовать и другой статический хостинг с HTTPS, например Netlify или Cloudflare Pages. Загружайте содержимое папки проекта целиком.

## 3. Установите на Android

1. Откройте HTTPS-ссылку в Chrome.
2. Нажмите меню ⋮ → **Установить приложение** или **Добавить на главный экран**.
3. Подтвердите установку. Значок iNotes появится среди приложений.

На втором устройстве откройте тот же адрес и войдите с тем же email и паролем.

## 4. Как пользоваться

- Нажмите «Новая заметка» для создания.
- Нажмите заметку в списке, чтобы редактировать.
- Используйте поле поиска и папки слева (на телефоне — кнопка меню).
- Значок булавки закрепляет заметку.
- Кнопка ☷ вставляет чек-лист.
- Кнопка ◐ переключает тёмную тему.
- Войдите через кнопку внизу боковой панели, чтобы включить облачную синхронизацию.

## Текущие ограничения этой версии

- Синхронизация Firebase активируется только после настройки собственного проекта и входа в аккаунт.
- Для облака требуется интернет; локальные изменения сохраняются в браузере и ожидают отправки при восстановлении соединения.
- Пока нет вложений, сканирования документов, рукописного ввода, совместного редактирования и восстановления удалённых заметок.
- Для установки PWA необходим HTTPS (кроме локальной разработки).


## Быстрая публикация только с Android через GitHub Pages

1. Распакуйте ZIP в приложении «Файлы» / Files.
2. В браузере откройте https://github.com/ и создайте бесплатный аккаунт или войдите.
3. Создайте новый репозиторий с именем `inotes` и включите `Public`.
4. В репозитории выберите **Add file → Upload files**.
5. Загрузите все файлы из распакованной папки (можно выбрать несколько файлов). Важно загрузить `index.html`, `app.js`, `styles.css`, `firebase-config.js`, `manifest.webmanifest`, `sw.js`, `icon-192.png` и `icon-512.png` в корень репозитория.
6. Нажмите **Commit changes**.
7. Откройте **Settings → Pages**. В разделе Build and deployment выберите **Deploy from a branch**, branch `main`, folder `/ (root)`, затем **Save**.
8. Подождите публикации и откройте `https://ВАШ-ЛОГИН.github.io/inotes/` в Chrome на Android.
9. В Chrome нажмите ⋮ → «Установить приложение» или «Добавить на главный экран».

После публикации настройте Firebase по разделу 1 выше и обновите файл `firebase-config.js` в GitHub. Не делитесь паролем Firebase Authentication с кем-либо.
